    JavaScript Console

    The JavaScript console is summoned by the icon in the window toolbar, by the icon for editing records in the datatable, and it is used as part of the value editor when the javascript code input method is used. However, if the aforementioned icons are not present in a host environment and the javascript input method is not available in the value editor, the reason is that the execution of JavaScript is blocked for the host by CSP rules.

    The chevron navigation below the textarea can be used to switch between saved JavaScript codes. If the navigation is in the first position, the letter u signals that the code is unsaved. The icons on the right side of the navigation appear depending on the state of the entered code. The icon is used to save a new code, the to update a changed code and the to delete a previously saved code.

    Predefined Objects

    Depending on where the JavaScript console is invoked, a number of predefined variables with objects are available for use in the code to be executed. The various purposes are the origin, database, and datatable views, which are accessed via the icons in the window title bar bar, as well as editing a table row and editing a single data value from within the Datatable.

    Variable Name Value Available for
    db Dexie database object as returned from await Dexie.open('dbname') of the currently selected database. database, datatable, table row, data value
    table Dexie Table object of the currently selected object store. datatable, table row, data value
    selection Dexie Collection object of the selected data records. datatable, table row, data value
    row a JavaScript object holding the data of a record that has been selected for editing. Only available when editing row data. datatable, table row, data value
    value The data value of the table cell that was selected for editing. Only available within the value editor. datatable, table row, data value
    Dexie A global Dexie instance that can be used to open other IndexedDB databases. origin, database, datatable, table row, data value

    Example Usages

    Here are some small examples that demonstrate the use of the predefined objects for code that can be executed via the JavaScript Console. If you are unfamiliar with the Dexie API, you will find many ideas and examples in its documentation.

    Use Dexie to create a new database and populate it with initial data:

    const loginsDb = new Dexie("LoginsDB");

loginsDb.version(1).stores({
    users: "++id, name, roleId",
    roles: "++id, name",
    logins: "++id, userId, startTimestamp"
});

loginsDb.on("populate", function() {
    db.users.add({ id: 1, name: "Jane", roleId: 1, passwordHash: "5fe7d592f69bf9b213618827fb45b2d9" });
    db.users.add({ id: 2, name: "Ed", roleId: 2, passwordHash: "ec046f7c1fd6b8021f1420eba4c2469a" });
    db.users.add({ id: 3, name: "Guest", roleId: 3 });
    db.roles.add({ id: 1, name: "admin" });
    db.roles.add({ id: 2, name: "user" });
    db.roles.add({ id: 3, name: "guest" });
});

loginsDb.open();

    Use db to copy data from the table initalData table to table:

    table.bulkPut(
   await db.table('initialData').toArray()
);

    Delete the selected rows from a table, which are represented by selection:

    selection.delete();

    Update table by changing timestamps stored in startedAt to Date objects:

    table.filter(entry => typeof entry.startedAt === 'number')
    .modify(entry => entry.startedAt = new Date(entry.startedAt));

    If the rows to be updated have been selected, they can be accessed as selection, and the previous example simplifies to:

    selection.modify(entry => entry.startedAt = new Date(entry.startedAt));

    Use Dexie to open the shopDb.sales table from another database and collect some data to update the displayed table:

    const counts = new Map();
const shopDb = await new Dexie('shop').open();

await shopDb.table('sales').each(sale => {
    counts.set(sale.userId, (counts.get(sale.userId) ?? 0) + 1);
});

await table.toCollection().modify(userStats => {
    userStats.salesCount = counts.get(userStats.userId ?? 0) ?? 0;
});

    To find out where two selected datasets differ, compare their data in selection:

    const selected = await selection.toArray();
const first = selected[0];
const second = selected[1];

for (prop in first) {
    if (typeof first[prop] !== 'string') continue;
    if (first[prop] !== second[prop]) {
        console.log(prop, first[prop], second[prop]);
    }
}

    Use properties of row to update a value in the Value Editor:

    const volume = 2 * Math.PI * row.radius * row.height;
return volume;

    With the execution method unsafeEval on Firefox the DOM of the website is accessible and used in this example to set the background image as a File value in the value editor:

    const div = document.querySelector('div.header');
const url = getComputedStyle(div).backgroundImage.slice(5, -2);
const filename = url.split('/').pop();
const response = await fetch(url);
const blob = await response.blob();

return new File([blob], filename, {
    type: blob.type,
    lastModified: Date.now(),
});
